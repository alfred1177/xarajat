# Закупки — Telegram Mini App для кухни

Повар составляет заявку → закупщик получает её списками по группам (для пересылки поставщикам) → на базаре отмечает
фактический вес и цену → приложение считает суммы → формируется PDF-накладная с номером, датой и подписями.

## Роли

| Роль | Что может |
|---|---|
| **Владелец** | всё: справочник групп и товаров, назначение ролей, заявки, закупка, история |
| **Повар** | создать заявку, смотреть заказы и историю, получить PDF |
| **Закупщик** | закупка: вес, цена, «Куплено» / «Нет», доп. товары, накладная; тексты для поставщиков |

Как добавить человека: он открывает бота и нажимает **Старт** → владельцу приходит уведомление →
**Настройки → Пользователи** → выбрать роль.

## Как работает заказ

1. Повар: вкладка **Заявка** → выбирает товары (поиск, группы, кнопки −/+ или ввод числа, например `3,5`) → «Отправить».
   Черновик сохраняется, если приложение случайно закрыли.
2. Закупщику (и владельцу) приходит сообщение со ссылкой на заказ и **отдельное сообщение на каждую группу**
   (Овощи, Бакалея…): его можно сразу переслать поставщику. В приложении у каждой группы есть кнопка «Копировать».
3. Закупщик на базаре: по каждой позиции вводит, сколько купил и цену за единицу, видит сумму и нажимает **✓ Куплено**
   (или **Нет**, если товара нет). Можно добавить товар не из заявки.
4. Когда отмечены все позиции, становится активна кнопка **📄 Сформировать накладную**. PDF приходит в чат
   закупщику, владельцу и повару.
5. Во вкладке **Заказы** хранится история; PDF можно получить повторно. Закрытый заказ можно открыть для исправлений.

## Запуск: пошагово

### Шаг 1. Создать бота
1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя → получите **токен** (никому не показывайте).
2. Узнайте свой Telegram ID: напишите **@userinfobot**.

### Шаг 2. Сервер и домен
Telegram открывает Mini App **только по HTTPS**, поэтому нужны:
- **VPS** с Ubuntu (1 ГБ ОЗУ достаточно) у любого провайдера;
- **домен или поддомен**, направленный на IP сервера (DNS-запись типа A). Например, `zakupki.вашдомен.uz`.
  Подойдёт и бесплатный поддомен (например, DuckDNS).

Сертификат HTTPS выпускается автоматически (Caddy), настраивать ничего не нужно.

### Шаг 3. Установка на сервер
```bash
# на сервере (Ubuntu)
curl -fsSL https://get.docker.com | sh
git clone <ссылка-на-ваш-репозиторий> zakupki
cd zakupki
cp .env.example .env
nano .env        # вписать BOT_TOKEN, OWNER_IDS, WEBAPP_URL, DOMAIN, ORG_NAME
docker compose up -d --build
docker compose logs -f app   # проверить, что запустилось (выход: Ctrl+C)
```

### Шаг 4. Проверка
Откройте бота → **/start** → кнопка **«🛒 Открыть закупки»** (кнопка «Закупки» появится и в меню рядом с полем ввода).
Сначала в **Настройки → Группы и товары** внесите справочник, затем назначьте роли повару и закупщику.

### Обновление и резервные копии
```bash
git pull && docker compose up -d --build   # обновить
./scripts/backup.sh                         # копия базы в backups/ (хранятся последние 30)
```
Вся база — один файл `data/zakupki.db`. Рекомендуется добавить бэкап в cron, например ежедневно:
`0 3 * * * cd /root/zakupki && ./scripts/backup.sh`.

## Для разработчика

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q                       # тесты
python scripts/dev_server.py    # интерфейс без Telegram: http://localhost:8080/?dev=1
                                # dev=1 владелец, dev=2 закупщик, dev=3 повар (демо-товары)
```

Стек: Python 3.13, aiogram 3 (бот), FastAPI (API + раздача Mini App), SQLite, reportlab (PDF, шрифт DejaVu),
интерфейс на чистом JS без сборки.

Структура:
```
app/config.py   настройки из .env
app/db.py       схема SQLite и запросы
app/api.py      HTTP API, проверка подписи Telegram, права ролей
app/bot.py      /start, кнопка Mini App, уведомления и отправка PDF
app/pdf.py      накладная
app/texts.py    форматирование чисел и тексты для поставщиков
app/main.py     запуск бота и веб-сервера одним процессом
webapp/         интерфейс Mini App
```

Безопасность: каждый запрос из Mini App проверяется по подписи Telegram (`initData`, HMAC от токена бота),
устаревшая подпись (более 24 ч) отклоняется. `DEV_MODE=1` отключает проверку — только для локальной отладки.
